# Security Policy

Hermes Synth is a web-based AI agent platform deployed on Cloudflare Pages.

## Reporting a Vulnerability

Please report security issues **privately** so we can fix them before disclosure:

- Open a [private security advisory](https://github.com/hermesSynth/hermes-synth/security/advisories/new) on this repository.

Please do **not** open a public issue for a suspected vulnerability.

## What to Expect

- We aim to acknowledge your report within **3 business days**.
- We'll keep you updated as we investigate and work on a fix.
- We practice coordinated disclosure: please allow a reasonable window for a fix to ship before
  publishing details.

## Scope

In scope: the Hermes Synth web application and this repository.

Out of scope: third-party AI providers (Venice AI, OpenAI, Anthropic) and Cloudflare infrastructure —
report those to the respective vendors.
