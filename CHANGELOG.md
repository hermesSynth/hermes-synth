# Changelog

All notable changes to Hermes Synth are documented here.

## [1.0.0] — 2026-05-27

Initial public release.

### Added
- AI Chat with multi-model support (Llama 3.3 70B, 405B, DeepSeek R1, Qwen 2.5) via Venice AI
- Agent system — create, edit, delete, and chat with custom AI agents
- Code Editor — create projects, edit files, run code (multi-language via AI)
- AI-powered Terminal — real DB commands + AI interpretation for unknown commands
- Command Center — 14+ commands with real-time D1 database stats
- Skills — create and run custom JavaScript skills
- Tasks — autonomous AI task execution with step breakdown
- Cron Jobs — schedule recurring tasks (5min to daily intervals)
- Browser — web scraping, link extraction, AI summarization
- Wallet — credits balance, transaction history, API key management
- Settings — Agent Config, API Keys, Plugins, Profiles, Theme, Notifications
- Authentication — Google OAuth, GitHub OAuth, Email/Password
- Email verification — 6-digit code via Resend (noreply@hermessynth.org)
- Dark theme UI with JetBrains Mono font (#0a0a0a + #ff8c00 orange accent)
- Cloudflare D1 database with 12 tables
- 41 serverless API functions
